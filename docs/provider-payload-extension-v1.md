# Provider payload and artifact contract

This is part of the single Provider protocol target. P0 supports inline nested JSON. P1 adds Host-owned artifact references and streaming within that same protocol. The historical filename is retained for inbound links.

- JSON arguments and results use ordinary nested values and the operation's trusted schemas. Validate before sending. Binary slots carry Host-issued references, validated and resolved via the published Host contract. Reject raw paths, arbitrary URLs, base64 byte transport and caller-supplied Content-IDs as transfer mechanisms.
- Stream binary and multipart through the shared Payload Engine using invocation-scoped readers and a Host-owned sink. The embedded Catalog declares media types, part names, required parts and JSON Pointer mappings. Handle escaped pointer segments and array indexes. The Payload Engine constructs wire Content-IDs and MIME boundaries, writes the JSON root first for multipart/related, and validates declared response parts and references.
- Enforce request, response, part-count, per-part and aggregate bounds. Respect one effective invocation context for transport, readers and sinks. Abort and close on cancellation, timeout or failed validation. Publish attachment references only after successful validation and Host finalization. Report failures without logging references, paths or sensitive data.
- Keep Host reference identity independent of upstream Content-ID. Provider keeps no persistent artifact namespace. Follow [Host integration](host-integration.md) for the unresolved cross-repository contract.

P1 acceptance requires cross-repository binary and multipart invoke tests with streamed bytes, nested pointer round trips, content type/size/digest checks, and negative cases for foreign, expired or missing references, undeclared/missing/duplicate parts, malformed/truncated MIME, limits, cancellation and partial-output cleanup. Local fakes are useful fixture evidence. Record real-NF multipart acceptance separately when a source-verified deployed operation is available.
